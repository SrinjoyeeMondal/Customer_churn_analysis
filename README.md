# Customer Churn Analysis

This repository contains a Jupyter notebook for customer churn analysis.

Notes:
- Raw data files (Excel, SQLite DB) are excluded via `.gitignore` and are not committed.
- To reproduce the analysis, place `customer_churn_data_raw.xlsx` in the repository (not committed) or use your own dataset.

Files to run:
- `churn_analysis.ipynb` — main notebook.
